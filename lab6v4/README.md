## 1. Мета роботи
Практично розібратися з принципами ООП у C#, реалізувати коректну ієрархію класів, налаштувати роботу з властивостями, конструкторами та обробкою даних відповідно до завдання варіанта №4.

## 2. Що було зроблено (Завдання)
1. Створено консольний проєкт на .NET у папці `lab6v4`.
2. Описано базові та похідні класи із закритими полями (`private`) для дотримання інкапсуляції.
3. Реалізовано властивості (`get`, `set`) з базовою перевіркою вхідних значень.
4. Перевизначено метод `ToString()` для зручного виводу об'єктів у консоль.
5. У файлі `Program.cs` написано сценарій перевірки: створення об'єктів, виклик їхніх методів та вивід результатів.

## 3. Код та структура проєкту

* `lab6v4.csproj` — конфігураційний файл проєкту.
